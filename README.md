# DAT603 Project Assignment

## Swedish Auto Insurance Data Analysis

This project analyses the Swedish Auto Insurance dataset, which contains 63 observations from geographical zones in Sweden. The variable X represents the number of claims per zone, and Y represents the total payment for all claims in thousands of Swedish Kronor (SEK).

## Analysis Performed

1. **Exploratory Data Analysis**
   - Histograms of X and Y
   - Scatter plot of Y against X
   - Boxplots with outlier detection

2. **Correlation Analysis**
   - Pearson's product-moment correlation
   - Spearman's rank correlation
   - Kendall's tau correlation

3. **Linear Regression**
   - OLS regression of Y on X
   - Goodness-of-fit testing
   - Significance testing of regression parameters
   - Predictions

## Files

- `analysis.ipynb` - Jupyter notebook with the full analysis
- `Swedish_Auto_Insurance_Data.csv` - The dataset
